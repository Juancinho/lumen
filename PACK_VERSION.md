# Lumen agent pack version

**Version:** 0.2.0 — Semantic Command Center refinement  
**Date:** 2026-10-07

Major changes from the initial pack:

- product scope expanded from semantic search to universal Windows command center;
- Alfred/Raycast-inspired actions, snippets, clipboard, quicklinks and workflows;
- universal provider/result/action domain model;
- Semantic Drop, Context Lens, Semantic Workspaces and opt-in Rewind;
- strict roadmap sequencing to prevent scope explosion;
- shell-agnostic Rust core and explicit Tauri/React boundary;
- one-WebView and memory/resource rules;
- multi-pass resumable indexing guidance for very large corpora;
- stronger Codex ↔ Claude handoff/prompts.
